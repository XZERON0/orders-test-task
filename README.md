# Заказы — тестовое задание

Небольшой модуль «заказы + склад» на том же стеке, что и наш продукт:

- **backend** — Node.js 20+, Express 5, Prisma 7 (Postgres), zod, Vitest + supertest
- **frontend** — Next.js 16 (App Router), React 19, TanStack Query

Сами задачи — в документе с заданием. Здесь только про запуск и устройство проекта.

## Запуск

Нужны Node.js 20+, pnpm 9 (`corepack enable`) и Postgres. Postgres можно поднять из `docker-compose.yml`
(порт 5433) или взять свой — тогда поправьте строки подключения в `backend/.env`.

```bash
pnpm install
cp backend/.env.example backend/.env
pnpm db:up            # Postgres в docker; пропустите, если у вас свой
pnpm run db:setup     # создать базу, схему и демо-данные. Именно `run`: `pnpm setup` — встроенная команда pnpm
pnpm dev:backend      # API на http://localhost:4000/api
pnpm dev:frontend     # интерфейс на http://localhost:3000
pnpm test             # тесты backend (своя база orders_test, создаётся сама)
pnpm typecheck
```

`pnpm run db:setup` можно запускать повторно — он пересоздаёт демо-данные с нуля.

## Пользователи

Вместо настоящего входа — переключатель в правом верхнем углу интерфейса. В API — заголовок
`Authorization: Bearer <токен>`.

| Пользователь | Организация    | Токен    |
|--------------|----------------|----------|
| Алия         | ТОО «Ромашка»  | `aliya`  |
| Бекзат       | ИП «Береке»    | `bekzat` |

Организации — разные компании-клиенты одного сервиса. Данные одной не должны быть видны другой.

## Как устроено

**Заказ** проходит статусы: черновик → подтверждён → отгружен; черновик и подтверждённый можно отменить.

| Действие      | API                             | Что происходит со складом                          |
|---------------|---------------------------------|----------------------------------------------------|
| создать       | `POST /api/orders`              | ничего, это черновик                               |
| подтвердить   | `POST /api/orders/:id/confirm`  | товар резервируется под заказ                      |
| отгрузить     | `POST /api/orders/:id/ship`     | товар списывается с полки, резерв снимается        |
| отменить      | `POST /api/orders/:id/cancel`   | резерв подтверждённого заказа возвращается         |

**Остаток** товара: «на складе» (`onHand`) — физически на полке, «в резерве» (`reserved`) — обещано
подтверждённым заказам, «доступно» = на складе − в резерве. Посмотреть — страница «Остатки» или
`GET /api/products`.

**Деньги** — тенге с двумя знаками после запятой (тиыны). Скидка заказа в процентах применяется к каждой строке.

```
backend/
  prisma/schema.prisma        схема базы
  prisma/seed.ts              демо-данные
  src/modules/orders/         заказы: роуты, сервис, валидация
  src/modules/products/       каталог с остатками
  src/lib/money.ts            денежные вычисления
  tests/                      тесты (helpers.ts — фикстуры и запросы от имени пользователя)
frontend/
  src/app/                    страницы: заказы, карточка заказа, новый заказ, остатки
  src/lib/orders.ts           запросы и мутации (TanStack Query)
```
